# techstore-frontend

![CI](https://github.com/jpdevelopment/techstore-frontend/actions/workflows/ci.yml/badge.svg)

Frontend de Techstore

Interfaz de TechStore, un catálogo de productos tecnológicos. React + TypeScript (Vite).

Consume la API de [techstore-backend](https://github.com/jpdevelopment/techstore-backend).

## Cómo contribuir

Lee [CONTRIBUTING.md](CONTRIBUTING.md) antes de abrir tu primer Pull Request.

## Desarrollo

Requisitos: la versión de Node indicada en `.nvmrc`.

| Comando          | Qué hace                                           |
| ---------------- | -------------------------------------------------- |
| `npm install`    | Instala dependencias y registra los hooks de Git   |
| `npm run dev`    | Servidor de desarrollo                             |
| `npm run build`  | Compila para producción                            |
| `npm run check`  | Lint, formato y tipos (lo mismo que ejecuta el CI) |
| `npm run format` | Da formato al código                               |
